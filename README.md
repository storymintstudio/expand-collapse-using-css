# Pure CSS Accordion

A clean, animated accordion built with **zero JavaScript** — just HTML & CSS.

## ✨ Features
- No JavaScript used
- Smooth open/close animation
- Built with checkbox + sibling selector trick
- Dark themed UI

## 🛠️ Tech Used
- HTML
- CSS

## 🚀 How it works
Uses a hidden checkbox input and the CSS `~` sibling selector to toggle content visibility. Animation is achieved using `max-height` transition.
