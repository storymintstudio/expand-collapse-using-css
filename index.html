Uses a hidden checkbox and label combination to create a fully functional accordion without JavaScript.

input:checked ~ .accordion-content

The general sibling selector (~) targets content that appears after the checked checkbox.

input:checked ~ .panel

Since CSS cannot animate height:auto, we animate max-height to create a smooth expanding effect.

transition: max-height 0.45s ease;

The :has() pseudo-class allows the parent accordion item to react when its checkbox is checked.

.accordion-item:has(input:checked)
